After step one: read the list first

Read requirements.txt first

After you clone a project (git clone), open this file first. It lists what goes into the box. Then install.

The demo, today
rich==15.0.0

One library. == means exactly this version. Not newer, not older.

The demo, after the Lab
rich==15.0.0
tabulate==0.10.0

Use a new library? Add a line. You do it in PART 2.

  • How many libraries? Each line is one library from other people. More lines, more to check.
  • Is every line pinned? A line with == is pinned (fixed to one version). A line without == can install a different version tomorrow. Then your code may stop working.
  • Is it on our whitelist (the course's list of safe libraries)? See slide 10.

Step two of four

One command fills the box

pip install -r requirements.txt reads the list. It installs every line. This is a real run in a new box:

> pip install -r requirements.txt
Collecting rich==15.0.0 (from -r requirements.txt (line 1))
...
Successfully installed markdown-it-py-4.2.0 mdurl-0.1.2 pygments-2.21.0 rich-15.0.0
  • You asked for one library and got four. rich needs three smaller libraries. pip brings them too. They are called dependencies (libraries that another library needs).
  • It is safe to run again. The second time, it says Requirement already satisfied. Nothing changes.
Course rule

Never install without a version. Not pip install tabulate, but pip install tabulate==0.10.0. Without a version, 37 people get different versions. Then the code works only on some computers.

The library of the day

rich in three seconds:
print, Table, Panel

rich makes terminal output look like a real application. You met it in Chapter 3. Today you use three of its parts.

print

Colour with tags

from rich import print
print("[bold green]hello[/]")
This print replaces Python's own print. The part in square brackets sets the style. [/] ends the style.

Table

Columns, then rows

table.add_row("Git", "...")

Which libraries you may use

PyPI has hundreds of thousands of libraries. The whitelist is a short list. The instructor checked every library on it. So no class time is lost on a library that does not install.
