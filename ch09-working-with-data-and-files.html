The shape of the data

Table data is rows and columns

A CSV file (comma-separated values) is plain text. The first line holds the column names. Every other line is one row. Our file describes twelve servers.

name,cpu,memory,disk,status
web-01,35,52,41,ok
web-02,42,61,85,ok
db-01,78,88,92,warn
...                       (12 rows in total)
Column

One kind of value

disk is always a number (percent used). status is always ok or warn.

Row

One thing

One server, with all five of its values on one line.

DataFrame

The table in Python

pandas reads the file into a DataFrame (a table object with named columns and numbered rows).

Step 3 · Filter

Keep only the rows you need

df["disk"] > 80 makes one True/False value for each row. Put it inside df[ ] and only the True rows stay.

Step 1 gives one True/False for each row. Step 2 keeps the True rows.

df_disk = df[df["disk"] > 80]
df_warn = df[df["status"] == "warn"]
df_both = df[(df["disk"] > 80) & (df["status"] == "warn")]
print(len(df_disk), len(df_warn), len(df_both))
4 4 2
Two conditions

Use & and round brackets

Write &, not and. Put each condition in its own ( ). Without the brackets you get a TypeError; with and you get a ValueError.

Short form

df.disk is df["disk"]

You will see df[df.disk > 80] online. It does the same thing. We write df["disk"] today because it works for every column name, even one with a space in it.

Two more tools

Sort the rows,
add a column

print(df.sort_values("disk", ascending=False).head(3))
        name  cpu  memory  disk status
5    file-01   18      40    97   warn
2      db-01   78      88    92   warn
6  backup-01   12      30    88     ok
df["disk_free"] = 100 - df["disk"]
print(df[["name", "disk", "disk_free"]].head(3))
     name  disk  disk_free
0  web-01    41         59
1  web-02    85         15
2   db-01    92          8
Notice

Sorting keeps the old index (5, 2, 6). A new column is computed for every row at the same time — no for loop. None of this changes the CSV file on disk. Only the DataFrame in memory changes.

Step 4 · Save

to_excel writes an .xlsx file
with openpyxl

df_warn.to_excel("warn.xlsx", index=False)
back = pd.read_excel("warn.xlsx")
print(back)
      name  cpu  memory  disk status
0    db-01   78      88    92   warn
1  file-01   18      40    97   warn
2   vpn-01   91      64    47   warn
3   app-01   87      93    55   warn
Engine

pandas asks openpyxl to do it

pandas does not write Excel files itself. It hands the work to openpyxl (the engine). That is why you install both libraries.

index=False

Leave the index out

Without it, the row labels become an extra first column. Read the file back and that column is called Unnamed: 0.

import argparse

import pandas as pd
from rich.console import Console
from rich.table import Table

parser = argparse.ArgumentParser(description="Filter a CSV file and save the result.")
parser.add_argument("csv_path", help="path to the CSV file")
args = parser.parse_args()

df = pd.read_csv(args.csv_path)
result = df[df["disk"] > 80]          # your filter goes here

table = Table(title=f"{len(result)} rows from {args.csv_path}")
for col in result.columns:
    table.add_column(col)
for row in result.itertuples(index=False):
    table.add_row(*[str(value) for value in row])
Console().print(table)

result.to_excel("result.xlsx", index=False)
print("Saved result.xlsx")

Why argparse: it reads the CSV path from the command line, like --name in Chapter 8. The rest is PART 2. * gives the list to add_row as separate values.
